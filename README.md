# ublock-filters

PC·휴대폰·태블릿 Firefox의 uBlock Origin이 함께 구독하는 사용자 필터 목록입니다.

## 구독

uBlock Origin 대시보드 → 필터 목록 → 맨 아래 "가져오기"에 아래 주소를 넣고 "변경사항 적용"을 누릅니다.

```
https://raw.githubusercontent.com/kdmo-o/ublock-filters/main/filters.txt
```

`! Expires: 6 hours` 설정에 따라 각 기기가 6시간마다 새 버전을 받습니다.

## 규칙 추가

`filters.txt`에 규칙을 추가하고 push하면 모든 기기에 반영됩니다. `trusted-` 스크립틀릿이나 `replace=` 같은 신뢰 필요 규칙은 구독 목록에서 동작하지 않으므로 각 기기의 "내 필터"에 둡니다.
